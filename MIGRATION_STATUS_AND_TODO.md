- [ ] **Финальная фиксация нестандартного порта SSH:**
  - Сейчас в Ubuntu 24.04 активен механизм `ssh.socket`.
  - Рекомендуется через VNC-консоль хостинга (или Telegram-команду `/sos_fix_ssh`):
    1. Отключить `ssh.socket`: `systemctl disable --now ssh.socket`
    2. Включить классическую службу: `systemctl enable --now ssh.service`
    3. Задать в `/etc/ssh/sshd_config.d/custom.conf` порт `1993`
    4. Проверить работу и отключить стандартный порт 22, чтобы бот-сканеры интернета не создавали фоновую нагрузку.
