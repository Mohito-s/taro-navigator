# Навык: Наполнение читалки книг Таро

## Инфраструктура уже готова (не трогай)

Все компоненты читалки РАБОТАЮТ на проде (shadowlinkapp.online):

- **HTML-модалка** `#book-modal` в `index.html` (строки ~548-574)
- **CSS** в `css/style.css` — `.book-reader__content`, `.book-reader__quote`, `.book-modal__header`
- **JS** функция `openBookModal(book)` в `js/app.js` (строки ~1107-1190)
- **Массив** `TARO_BOOKS` в `js/app.js` (строки ~651-960) — 8 книг
- **Эталон**: книга b1 (Рэйчел Поллак) — 7 полных глав, используй как образец

## Логика кнопок (исправлена, commit 3a38ba2)

- Кнопка **«Читать главы книги»** — всегда показывается, открывает главу 0
- Кнопка **«Открыть полный PDF»** — появляется только если у книги есть `pdfUrl`

## Структура одной главы

```javascript
{
  title: "ЭМОДЗИ Название вкладки",
  content: `
    <h3>Заголовок раздела</h3>
    <p>Параграф текста...</p>
    <h4>Подзаголовок</h4>
    <ul>
      <li><b>Термин:</b> объяснение</li>
    </ul>
    <div class="book-reader__quote">Цитата из книги</div>
  `
}
```

**Допустимые теги:** `h3`, `h4`, `p`, `ul`, `ol`, `li`, `b`, `em`, `div.book-reader__quote`

**ЗАПРЕЩЕНО:** `img`, `script`, inline `style=""`, внешние `<a href=...>`

## Протокол работы

1. **Прочитай** `PROJECT_STATE.md` в корне (ПЛАН + ЛОГ ИСПРАВЛЕНИЙ)
2. **Открой** `js/app.js`, найди книгу в `TARO_BOOKS` (строки ~651-960)
3. **Правь только через Edit/Write инструмент** — PowerShell ломает UTF-8!
4. **Проверь** после каждой правки:
   - `node --check js/app.js` — синтаксис
   - UTF-8: `python -c "raw=open('js/app.js','rb').read(); print(raw[:3]==b'\xef\xbb\xbf', raw.decode('utf-8','replace').count(chr(0xFFFD)))"` → `False 0`
5. **Задеплой** (каждую книгу отдельным коммитом):
   ```
   git add js/app.js
   git commit -m "content: add chapters for НАЗВАНИЕ_КНИГИ"
   git push origin main
   ```
   Потом на VPS (SSH порт 1993, не 22):
   ```
   cd ~/apps/taro-navigator && git pull
   ```
6. **Обнови** `PROJECT_STATE.md` — добавь запись в ЛОГ ИСПРАВЛЕНИЙ сверху

## Стиль текста

- Язык: **русский**, обращение на **«ты»**
- Тон: интеллектуальный и живой, не сухой справочник, не пафосная мистика
- Длина главы: **150-350 слов** (удобно читать на мобилке в модалке)
- Минимум **одна** `<div class="book-reader__quote">` на каждую главу
- Глубину в каббалу/астрологию — давай обзорно, без деталей

## НЕЛЬЗЯ менять

- `id`, `title`, `author`, `year`, `coverImage`, `pdfUrl` существующих книг
- `css/style.css` — стили читалки уже настроены идеально
- `index.html` — HTML модалки готов (две кнопки: Read + PDF)
- PDF-вкладка добавляется автоматически из `pdfUrl` — не трогай
